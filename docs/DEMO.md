# Proxima Demo Guide

No screenshots or hosted demo are bundled in this source release. Record a short walkthrough with a development account and data you can share:

1. Search for a role, apply location/work-mode filters, and open the detail page.
2. Show a company profile and its available roles.
3. Use an admin account to register a company with a supported public careers URL, then show its scraper run history.
4. Explain the README architecture diagram and show enrichment fields when available. Do not promise a fixed processing delay.
5. Save a role and track an application in the user profile.

Capture job search, company registration, and scraper history. Optional additions are job details and the application tracker. Redact emails, profile images, credentials, session data, and private monitoring URLs. Do not capture developer tools containing cookies or authorization headers.

Put real images in the frontend's `docs/screenshots/` directory and embed their actual paths in its README. Add hosted URLs only after they exist. Treat displayed job counts as a dated demo snapshot, not a claim of user adoption.
